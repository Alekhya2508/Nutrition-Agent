subagent
Spawn isolated subagent contexts

Launch pre-defined workflow sequences

MCP Extension Architecture
🖥️Local (stdio)
Starts as child process via node / python / docker / uv
Communicates over stdin/stdout
Config: command, args, env in mcp_settings.json
☁️Remote (SSE / HTTP)
Connects to external URL over Server-Sent Events or HTTP
Supports Bearer / API key auth
Tools discovered at runtime via MCP handshake
Marketplace: Community-contributed MCP servers (databases, cloud APIs, dev tools) and custom modes — installable directly from the Bob Settings panel.
